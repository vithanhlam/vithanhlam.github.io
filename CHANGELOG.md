Rebuilt the Neko Paint landing page into a full online CV / portfolio.

### Added
- Single-page CV: hero, stats, services, process, products, apps, open source, journey, skills and contact sections.
- English / Vietnamese language toggle (English by default, choice is remembered).
- Dark / light theme toggle and print-friendly layout ("Download CV (PDF)").
- Animated 3D tech background (rotating node network and perspective grid), respects reduced-motion.
- Services section: AI agents & automation, CRM, ERP, e-commerce, WordPress & web platforms, mobile apps.
- Six main products with real app icons (`assets/`): ShieldPress, ShieldPress Terminal, Reqnora, Neko Paint, Tra Cứu Biển Số Xe and the CodeWP Shield Monitor WordPress plugin.
- Links to Google Play, App Store, reqnora.com, WordPress.org plugin page, GitHub, YouTube and Facebook.
- Live GitHub repository cards loaded from the GitHub API (static fallback included).
- Font Awesome 6 icons.
- WordPress plugin tile in the stats row.

- Larger base font size and glass-style cards over the animated background.
